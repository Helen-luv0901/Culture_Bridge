# 手動測試清單（D-15）

每次上線前在測試站跑一次。打勾、記下瀏覽器／裝置與日期；有問題開 issue 並附截圖。

## 測試環境

- [ ] 寬度 320、375、768、1024、1440（Chrome 開發者工具或實機）
- [ ] 文字放大 200%（瀏覽器縮放或系統字級）
- [ ] 繁中與 English 各跑一次核心流程
- [ ] 網頁版：Chrome、Safari（iPhone）、Edge 至少各一
- [ ] Android 實機至少 3 種（C-19）

## 版面與無障礙（每個寬度）

- [ ] 首頁、探索、分享、我的、流程詳情、辦理進度、完成回饋、經驗詳情、登入頁：沒有被裁切、沒有水平捲動
- [ ] 手機底部 4 個分頁、平板與桌機左側導覽正常；目前所在分頁有標示
- [ ] 「問助理」按鈕不擋住主要按鈕
- [ ] 只用鍵盤（Tab／Enter）可以完成分享流程，焦點看得見
- [ ] 按鈕、勾選框的觸控範圍至少 44px
- [ ] 螢幕閱讀器（TalkBack／VoiceOver）讀得出按鈕名稱與步驟狀態

## 登入

- [ ] 未登入可以瀏覽首頁、探索、經驗詳情、流程詳情
- [ ] 未登入按「開始辦理」「分享」「有幫助」→ 進入登入頁，登入後回到原頁
- [ ] Google 登入成功；登出後「我的」不再顯示個人資料
- [ ] 重新整理頁面仍保持登入

## 制度流程

- [ ] 流程卡顯示驗證狀態；已驗證的有最後確認日期，待確認的有提醒
- [ ] 來源可點開官方網址
- [ ] 開始辦理 → 進度頁；勾選步驟後進度數字與進度條更新
- [ ] 重新整理後進度還在；首頁出現「我的辦理流程」
- [ ] 「我卡住了」→ 選原因、填說明 → 送出；步驟變成卡關顏色
- [ ] 完成回饋選「流程不同」+ 類別 → 送出；回到首頁、該流程不再在進行中
- [ ] 審查者在後台「回報審查」看得到剛才的回報

## 分享經驗

- [ ] 空白時不能送出，有提示
- [ ] 2000 字上限
- [ ] 「請 AI 幫我整理」→ 摘要確認頁；可修改情境與提醒
- [ ] 回去修改原話後，舊摘要不能發布（會要求重新整理）
- [ ] 確認發布 → 「我的」顯示已發布；探索看得到，且不顯示任何作者資訊
- [ ] 幾分鐘後經驗有 AI 翻譯，切換語言時顯示「AI 翻譯」與原文切換
- [ ] AI 服務停用時顯示「暫時無法使用」，原話保留為草稿
- [ ] 從經驗詳情按「我的經驗不同」分享 → 原經驗顯示「不同學生怎麼說」

## 暱稱、真名與署名

- [ ] 第一次登入（沒有填過名字）會出現「歡迎！要怎麼稱呼你？」，可以儲存或「稍後再說」，之後回到原本的頁面
- [ ] 「我的」→「個人資料」可以修改或清空暱稱與真名
- [ ] 發布時可選「匿名／暱稱／真名」；沒填的名字不能選，選真名會出現「所有人都看得到」提醒
- [ ] 用暱稱發布的經驗在探索與經驗頁顯示暱稱；改暱稱後跟著變；清空後變回「匿名分享」
- [ ] 匿名發布的經驗看不到任何名字；AI 助理引用經驗時不帶名字

## 反應、收藏、檢舉、封鎖

- [ ] 「有幫助」「我也遇過」可按可取消，數字正確
- [ ] 經驗頁與探索卡片的書籤圖示：收藏後出現在「我的」→「收藏的經驗」，最新的在最上面；在「我的」按「取消收藏」後消失；其他帳號看不到你的收藏
- [ ] 收藏的經驗被隱藏、刪除或作者被你封鎖後，從收藏清單消失
- [ ] 檢舉：選原因送出；同一則不能重複檢舉
- [ ] 3 個不同帳號檢舉同一則 → 自動隱藏；審查者「檢舉不成立」後恢復
- [ ] 封鎖作者 → 該作者所有經驗都看不到；「我的」→ 已封鎖的作者 → 解除封鎖後恢復

## AI 助理

- [ ] 手機為下方面板、寬螢幕為側欄；關閉後頁面位置不變
- [ ] 問「工作證要準備什麼？」：回答附流程卡、驗證狀態、日期
- [ ] 在流程頁問「這個流程要多久？」能理解「這個」
- [ ] 問「幫我開始辦 ARC」→ 出現確認卡；按確認後進度頁出現該流程；不按確認則沒有任何改變
- [ ] 問沒有資料的問題 → 直接說沒有資料、建議問學校
- [ ] 清除對話後重新開始
- [ ] 快速連續送出超過每分鐘上限 → 顯示稍後再試

## 帳號

- [ ] 「我的」顯示語言切換、已封鎖的作者、登出、刪除帳號
- [ ] 刪除帳號 → 確認 → 回首頁；用同一 Google 帳號再登入時是全新的帳號，之前的經驗不見
- [ ] `/account-deletion` 頁面不用登入就能開

## 審查後台（reviewer／admin）

- [ ] 學生帳號開 `/admin` 看到「只有審查者與管理者可以使用」
- [ ] 新增流程 → 編輯步驟 → 加來源 → 發布 → 首頁出現
- [ ] 已發布版本不能直接改，只能「建立新版本」；學生辦到一半的舊版本顯示「已有新版本」
- [ ] 記錄審查「已驗證」後狀態變成已驗證；沒有來源時不能標已驗證
- [ ] 官方文件：加入後助理能引用；停用後不再引用
