# Google Play Console 其他聲明（草稿，D-12、B-23）

> **草稿，送出前請 D 與 A 確認。** 資料安全表單另見 [play-data-safety.md](play-data-safety.md)。Play Console 的題目會改，以實際畫面為準；標【待確認】的地方要先決定。政策細節送出前請到 [Play 政策中心](https://play.google/developer-content-policy/) 再確認一次。

## 1. 應用程式存取權（App access，B-23 審查用帳號）

Play 審查員要能用到所有功能。這個 App 的登入只有「使用 Google 帳號登入」，任何 Google 帳號都可以，所以**不需要另外提供帳號密碼**。

選「部分功能受限」，說明欄可填：

> 瀏覽流程與學生經驗不需登入。分享經驗、回應、記錄辦理進度、檢舉與封鎖、AI 助理需要登入：到「我的」→「使用 Google 帳號登入」，任何 Google 帳號皆可，不需邀請或另外的帳密。
>
> Browsing procedures and experiences needs no account. Sharing, reactions, procedure progress, reporting/blocking and the AI assistant need sign-in: open My → "Continue with Google". Any Google account works; no invitation or extra credentials are needed.

注意：

- 正式環境**不接受** `dev:` 測試 token（`APP_ENV` 不是 `development` 時一律回 401），所以不能拿開發用登入給審查員
- 管理介面（`/admin`）只給 reviewer／admin，不需要讓審查員看；如果 Google 要求，請審查員先登入一次，在「我的」→「帳號」看到帳號編號，再由 admin 在管理介面「權限」分頁暫時設成審查者，審查後按「移除權限」
- 送審前用一個**新的** Google 帳號從頭走一次：登入 → 分享 → 開始辦理 → 檢舉 → 刪除帳號，確認沒有卡在白名單或邀請碼

## 2. 廣告

- 應用程式是否含廣告：**否**（沒有任何廣告 SDK；隱私權政策也寫明不投放廣告）

## 3. 目標對象與內容

- 目標年齡層：**18 歲以上**【待確認：有沒有未滿 18 歲的華語生或交換生要使用】
  - 若勾到 13～17 歲，會多出「家庭」相關政策與額外審查，使用者內容與 AI 功能都要再檢查
- 是否可能吸引兒童：否（大學國際生的生活與行政流程）

## 4. 內容分級（IARC 問卷）

類別選「參考、新聞或教育」【以問卷畫面為準】。依目前功能預計的答案：

| 問題 | 答案 | 說明 |
|---|---|---|
| 暴力、血腥、恐怖 | 否 | |
| 性、裸露 | 否 | 社群規範禁止，檢舉原因有「色情內容」 |
| 粗俗語言 | 否 | App 本身沒有；使用者內容由檢舉處理（見下一列） |
| 管制藥物、菸酒 | 否 | |
| 賭博、模擬賭博 | 否 | |
| 使用者可以互動或交換內容 | **是** | 匿名分享經驗、反應（有幫助／我也遇過）、「我的經驗不同」；**沒有**私訊或聊天室 |
| 分享使用者位置 | 否 | 不要求位置權限 |
| 數位商品購買 | 否 | |
| 不受限的網路存取（內建瀏覽器） | 否 | 「看來源」用系統瀏覽器開官方網址 |

## 5. 其他宣告

- **新聞應用程式**：否
- **政府應用程式**：否。App 會整理移民署、勞動部、健保署等政府流程，但**不是**政府機關的 App。Play 對「提供政府資訊但非政府開發」的 App 要求在商店說明寫清楚沒有隸屬關係，並列出資訊來源網址；商店頁草稿已加上這段（見 [store-listing.md](store-listing.md)「資訊來源與聲明」）
- **金融功能**：無
- **健康功能**：無（健保、體檢只是行政流程說明，不提供醫療建議）
- **COVID-19、選舉、VPN 等特殊類別**：無
